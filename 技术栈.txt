个人博客项目技术栈总结

一、前端技术栈
- 核心框架：Vue 3（依赖版本：^3.5.31）
- 构建工具：Vite（依赖版本：^8.0.3）
- Vite 插件：@vitejs/plugin-vue、vite-plugin-vue-devtools
- 路由管理：Vue Router（依赖版本：^5.0.4）
- 状态管理：Pinia（依赖版本：^3.0.4）
- HTTP 请求：Axios（依赖版本：^1.14.0）
- 语言与模块规范：JavaScript、ES Module（package.json 中 type 为 module）
- Node.js 要求：^20.19.0 或 >=22.12.0
- 开发代理：Vite dev server 代理到后端 http://localhost:8080，包含 /clap、/images、/uploads、/musics、/posts、/visitor-stats 等接口路径

二、后端技术栈
- 开发语言：Java 17
- 后端框架：Spring Boot 3.5.13
- 构建与依赖管理：Maven
- Web 能力：spring-boot-starter-web，用于提供 REST 接口和静态资源访问
- ORM / 持久层：MyBatis Spring Boot Starter 3.0.5
- 数据库驱动：MySQL Connector/J
- 代码简化工具：Lombok
- 测试依赖：spring-boot-starter-test、mybatis-spring-boot-starter-test
- 服务端口：8080
- 项目分层：controller、service、service.impl、mapper、pojo、config
- 文件上传：Spring Multipart，单文件和单请求大小限制均为 3MB
- 静态资源：classpath:/static/，上传目录配置为 ./uploads
- 打包产物：Spring Boot 可执行 JAR（personal-blog-0.0.1-SNAPSHOT.jar）

三、数据库技术栈
- 数据库：MySQL
- 数据库名：blog_db
- 字符集与排序规则：utf8mb4、utf8mb4_unicode_ci
- 存储引擎：InnoDB
- 连接方式：JDBC（com.mysql.cj.jdbc.Driver）
- 后端配置的连接地址：jdbc:mysql://192.168.88.130:3306/blog_db?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
- 数据库备份文件：blog_db_backup.sql
- 备份来源信息：MySQL dump 10.13，Server version 9.6.0
- 主要数据表：clap、image、music、post、visitor_stat

四、整体架构
- 前后端分离架构
- 前端通过 Vite 开发服务器代理请求到 Spring Boot 后端
- 后端通过 MyBatis Mapper 访问 MySQL 数据库
- 项目包含博客帖子、图片上传、音乐资源、拍手统计、访客统计等功能模块
- 静态上传资源通过后端目录和接口路径对外提供访问
