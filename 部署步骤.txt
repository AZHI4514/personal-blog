个人博客 Ubuntu 云服务器部署步骤

项目识别结果：
- 前端：personal-blog-front，Vue 3 + Vite，构建命令 npm run build，产物目录 dist。
- 后端：personal-blog-back，Spring Boot 3.5 + Java 17 + Maven + MyBatis，默认端口 8080。
- 数据库：MySQL，库名建议 blog_db。
- 前端请求使用同源路径，例如 /posts、/images、/uploads、/musics、/clap、/visitor-stats；生产环境推荐用 Nginx 把这些路径反向代理到后端 8080。

一、购买云服务器前的建议

1. 系统选择
   - Ubuntu 22.04 LTS 或 Ubuntu 24.04 LTS。

2. 配置建议
   - 个人博客起步：1 核 2G 内存即可。
   - 如果 MySQL、前端、后端都放同一台机器，建议 2 核 2G 或 2 核 4G。
   - 磁盘建议 40GB 起步。

3. 网络与安全组
   - 放行 22 端口：SSH 登录。
   - 放行 80 端口：HTTP 访问。
   - 放行 443 端口：HTTPS 访问，后续配置证书时使用。
   - 不建议对公网放行 3306 端口，MySQL 只给本机后端访问即可。
   - 不建议对公网放行 8080 端口，后端由 Nginx 内部反向代理。

4. 域名
   - 如果有域名，把 A 记录解析到服务器公网 IP。
   - 没有域名也可以先用服务器公网 IP 访问。

二、登录服务器

本地执行：

ssh root@你的服务器公网IP

建议创建普通部署用户，例如 blog：

adduser blog
usermod -aG sudo blog

之后可以使用：

ssh blog@你的服务器公网IP

三、安装基础环境

更新系统：

sudo apt update
sudo apt upgrade -y

安装常用工具：

sudo apt install -y curl wget unzip git vim ufw

安装 Java 17：

sudo apt install -y openjdk-17-jdk
java -version

安装 Maven：

sudo apt install -y maven
mvn -version

安装 Node.js 20：

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node -v
npm -v

安装 Nginx：

sudo apt install -y nginx
sudo systemctl enable nginx
sudo systemctl start nginx

安装 MySQL：

sudo apt install -y mysql-server
sudo systemctl enable mysql
sudo systemctl start mysql

四、配置防火墙

如果使用 ufw：

sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw enable
sudo ufw status

注意：不要开放 MySQL 的 3306 端口到公网。

五、初始化 MySQL 数据库

进入 MySQL：

sudo mysql

创建数据库和用户，密码请改成你自己的强密码：

CREATE DATABASE blog_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'blog_user'@'localhost' IDENTIFIED BY '请改成强密码';
GRANT ALL PRIVILEGES ON blog_db.* TO 'blog_user'@'localhost';
FLUSH PRIVILEGES;
USE blog_db;

当前项目没有发现现成的 SQL 初始化脚本，下面是根据后端实体类和 Mapper 推断的表结构，部署前建议再按实际代码核对一次：

CREATE TABLE visitor_stat (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  ip VARCHAR(45) NOT NULL,
  total BIGINT NOT NULL DEFAULT 0,
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_visitor_stat_ip (ip)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE clap (
  id BIGINT PRIMARY KEY,
  total BIGINT NOT NULL DEFAULT 0
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

INSERT INTO clap (id, total) VALUES (1, 0)
ON DUPLICATE KEY UPDATE total = total;

CREATE TABLE image (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  path VARCHAR(500) NOT NULL,
  author VARCHAR(100),
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE music (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  title VARCHAR(200) NOT NULL,
  artist VARCHAR(200),
  file_path VARCHAR(500),
  cover_path VARCHAR(500),
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE post (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  parent_id BIGINT NULL,
  username VARCHAR(100),
  email VARCHAR(200),
  title VARCHAR(200),
  content TEXT,
  image_path VARCHAR(500),
  delete_key VARCHAR(200),
  create_time DATETIME,
  update_time DATETIME,
  INDEX idx_parent_id (parent_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE user(
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  username VARCHAR(100) NOT NULL UNIQUE,
  password VARCHAR(255) NOT NULL,
  email VARCHAR(200) NOT NULL UNIQUE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

退出 MySQL：

exit;

六、把项目上传到服务器

假设服务器上使用 /opt/personal-blog：

sudo mkdir -p /opt/personal-blog
sudo chown -R root:root /opt/personal-blog

方式 1：如果代码托管在 Git 仓库：

cd /opt/personal-blog
git clone 你的仓库地址 .

方式 2：如果直接从本机上传，在本机项目目录执行：

scp -r personal-blog-front personal-blog-back blog@你的服务器公网IP:/opt/personal-blog/

七、修改后端数据库配置

编辑后端配置文件：

vim /opt/personal-blog/personal-blog-back/src/main/resources/application.yml

把 datasource 改成服务器本机 MySQL，例如：

spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/blog_db?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: blog_user
    password: 你的MySQL密码

server:
  port: 8080

file:
  upload:
    path: ./uploads

重要：不要继续使用当前开发环境里的 192.168.88.130、root、1234 这类配置。

八、构建并部署后端

进入后端目录：

cd /opt/personal-blog/personal-blog-back

构建：

mvn clean package -DskipTests

创建运行目录：

mkdir -p /opt/personal-blog/backend
mkdir -p /opt/personal-blog/backend/uploads
cp target/personal-blog-0.0.1-SNAPSHOT.jar /opt/personal-blog/backend/app.jar

创建 systemd 服务：

sudo vim /etc/systemd/system/personal-blog-back.service

写入：

[Unit]
Description=Personal Blog Spring Boot Backend
After=network.target mysql.service

[Service]
User=root
WorkingDirectory=/opt/personal-blog/backend
ExecStart=/usr/bin/java -jar /opt/personal-blog/backend/app.jar
Restart=always
RestartSec=5
Environment=TZ=Asia/Shanghai

[Install]
WantedBy=multi-user.target

启动后端：

sudo systemctl daemon-reload
sudo systemctl enable personal-blog-back
sudo systemctl start personal-blog-back
sudo systemctl status personal-blog-back

查看日志：

journalctl -u personal-blog-back -f

本机测试后端：

curl http://127.0.0.1:8080/visitor-stats

九、构建并部署前端

进入前端目录：

cd /opt/personal-blog/personal-blog-front

安装依赖并构建：

npm install
npm run build

部署到 Nginx 静态目录：

sudo mkdir -p /var/www/personal-blog
sudo rm -rf /var/www/personal-blog/*
sudo cp -r dist/* /var/www/personal-blog/
sudo chown -R www-data:www-data /var/www/personal-blog

十、配置 Nginx

创建站点配置：

sudo vim /etc/nginx/sites-available/personal-blog

如果暂时没有域名，用服务器公网 IP 访问，可以写：

server {
    listen 80;
    server_name _;

    root /var/www/personal-blog;
    index index.html;

    client_max_body_size 10m;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /clap {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /images {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /uploads {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /musics {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /posts {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /visitor-stats {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

如果有域名，把 server_name _; 改成：

server_name 你的域名;

启用站点：

sudo ln -s /etc/nginx/sites-available/personal-blog /etc/nginx/sites-enabled/personal-blog
sudo nginx -t
sudo systemctl reload nginx

如果默认站点冲突，可以删除默认站点软链接：

sudo rm /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx

十一、访问测试

浏览器打开：

http://你的服务器公网IP

或者：

http://你的域名

重点测试：
- 首页是否能打开。
- 访客统计接口是否正常。
- 点赞接口是否正常。
- 图片列表是否能加载。
- 音乐列表是否能加载。
- 帖子创建、查询、回复、删除是否正常。
- 上传图片后 /uploads/... 是否能访问。

十二、配置 HTTPS，可选但推荐

如果已有域名并且解析已经生效，可以用 Certbot：

sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名

证书自动续期测试：

sudo certbot renew --dry-run

十四、常见问题排查

1. 页面能打开，但接口失败
   - 检查后端是否运行：sudo systemctl status personal-blog-back
   - 检查后端日志：journalctl -u personal-blog-back -f
   - 检查 Nginx 配置：sudo nginx -t
   - 检查接口是否能本机访问：curl http://127.0.0.1:8080/posts

2. 后端启动失败，提示数据库连接失败
   - 检查 MySQL 是否启动：sudo systemctl status mysql
   - 检查 application.yml 中 url、username、password 是否正确。
   - 确认数据库 blog_db 和用户 blog_user 已创建。

3. 上传图片后访问不到
   - 确认 systemd 服务的 WorkingDirectory 是 /opt/personal-blog/backend。
   - 确认 /opt/personal-blog/backend/uploads 存在且 blog 用户有写权限。
   - 检查后端 WebConfig 是否仍然映射 /uploads/** 到 file:uploads/。

4. 前端刷新某个页面 404
   - Nginx 的 location / 必须包含：try_files $uri $uri/ /index.html;

5. 服务器内存小，构建失败
   - 可以在本地构建前端和后端后，只上传 dist 和 jar。
   - 或者购买 2G 以上内存的服务器。

十五、部署完成后的安全建议

- MySQL 不开放公网 3306。
- 后端 8080 不开放公网，只通过 Nginx 代理。
- 数据库不要使用 root 用户给应用连接。
- application.yml 里的数据库密码不要提交到公开仓库。
- 定期备份 MySQL：

mysqldump -u blog_user -p blog_db > blog_db_backup.sql

- 定期备份上传文件目录：

tar -czf uploads_backup.tar.gz /opt/personal-blog/backend/uploads
