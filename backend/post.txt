                    七、调用流程总结
================================================================================

1. 创建文章流程：
   前端POST /posts (JSON: {username, content, deleteKey, ...})
   → PostController.createPost()
   → PostServiceImpl.createPost()
     → 验证内容、用户名、密钥
     → 设置时间戳
     → 验证父帖存在性（如果是回复）
     → PostMapper.insert() (INSERT INTO post ...)
     → 返回带ID的Post对象
   → Result.success(post)
   → JSON响应返回前端

2. 获取文章流程：
   前端GET /posts
   → PostController.getPosts()
   → PostServiceImpl.getAllPosts()
     → PostMapper.selectTopPosts() (查询主帖)
     → 遍历每个主帖
       → PostMapper.selectRepliesByParentId() (查询回复)
       → 设置replies和replyCount
     → 返回嵌套结构
   → Result.success(posts)
   → JSON响应返回前端

3. 删除文章流程：
   前端DELETE /posts/123 (JSON: {deleteKey: "xxx"})
   → PostController.deletePost(123, body)
   → PostServiceImpl.deletePost(123, "xxx")
     → 验证密钥不为空
     → PostMapper.selectById(123) 查询文章
     → 验证密钥匹配
     → 如果是主帖：PostMapper.deleteRepliesByParentId(123) 删除回复
     → PostMapper.deleteByIdAndKey(123, "xxx") 删除文章
   → Result.success()
   → JSON响应返回前端

4. 更新文章流程：
   前端PUT /posts/123 (JSON: {deleteKey, title, content, imagePath})
   → PostController.updatePost(123, body)
   → PostServiceImpl.updatePost(123, deleteKey, title, content, imagePath)
     → 验证密钥和内容不为空
     → PostMapper.selectById(123) 查询文章
     → 验证密钥匹配
     → 合并新旧数据
     → PostMapper.updateByIdAndKey() 执行更新
     → 更新内存对象
   → Result.success(post)
   → JSON响应返回前端

                    八、数据库表结构
================================================================================

根据Mapper中的SQL推断的表结构：

CREATE TABLE post (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,  -- 主键，自增
    parent_id BIGINT,                       -- 父帖ID，NULL表示主帖
    username VARCHAR(50),                   -- 用户名
    email VARCHAR(100),                     -- 邮箱
    title VARCHAR(200),                     -- 标题
    content TEXT,                           -- 内容
    image_path VARCHAR(500),                -- 图片路径
    delete_key VARCHAR(100) NOT NULL,       -- 删除密钥
    create_time DATETIME NOT NULL,          -- 创建时间
    update_time DATETIME NOT NULL,          -- 更新时间
    FOREIGN KEY (parent_id) REFERENCES post(id)  -- 外键约束
);
